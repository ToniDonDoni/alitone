# Purpose

Making sound in code.

# Now

The current experiment is the [procedural Tone.js march](references/march-of-the-fallen-tone.html). Open it in a desktop browser and press play.

## Repo

- `references/` — the source MP3 and pages used for listening comparisons.
- `specs/` — the music brief, implementation spec, and project notes.
- `analysis/` — audio measurements and comparison reports.
- `src/` — source code, patches, and page template.
- `tools/` — build, browser-check, and audio-analysis scripts.
- `thirdparty/` — Tone.js 15.1.22 source pinned as a Git submodule.
- `output/` — generated binary audio renders; ignored by Git.
